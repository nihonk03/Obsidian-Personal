Eres un ingeniero senior implementando **PitayaBot**, un asistente virtual por WhatsApp para la empresa Batidos Pitaya. ## Normalización de números de teléfono

WhatsApp entrega números como `50588112233@c.us`. La tabla Operarios guarda solo el número local, ej: `88112233`. El país siempre es +505 (Nicaragua).

```javascript
// Copiar lógica de normalización de wsp-crmbot/src/utils/phone.js
// Si no existe, implementar:
function normalizarNumero(jid) {
  // '50588112233@c.us' → '88112233'
  const numero = jid.replace('@c.us', '').replace('@g.us', '');
  // Quitar prefijo 505 si está presente
  return numero.startsWith('505') ? numero.slice(3) : numero;
}
```

## Identificación de usuario por número

Cada vez que llega un mensaje, el primer paso es identificar al operario:

```
1. Extraer número del remitente y normalizar
2. GET api.batidospitaya.com/api/bot/auth/identificar.php?celular=88112233
3. El PHP busca en Operarios WHERE telefono_corporativo = ? y en algun registro en Contratos donde Finalizado=0
4. También verifica permiso 'pitayabot' en tools_erp
5. Si no encontrado → responder "No estás registrado. Contacta a RRHH."
6. Si encontrado → continuar con el mensaje
```

## 1.5 — Flujo de confirmación (confirmManager.js)

```
Mensaje recibe → clasificar → si confianza < 0.7 o ambiguo = true:
  → preguntar al usuario qué quiso decir

Si confianza >= 0.7:
  → guardar estado en BD (bot_estado_confirmacion, expira en 5 min)
  → enviar al usuario: "frase_confirmacion — ¿Confirmas? Responde *sí* o *no*"

Respuesta del usuario:
  → Si "sí" / "si" / "confirmo" / "dale" / "ok" / "correcto":
      → ejecutar la acción → borrar estado → registrar log
  → Si "no" / "cancelar" / "cancela":
      → borrar estado → responder "Entendido, acción cancelada."
  → Si cualquier otra cosa:
      → clasificar como nuevo mensaje (ignorar estado anterior)
```

## 1.6 — Endpoint PHP: auth/identificar.php

```php
<?php
// api/bot/auth/identificar.php
// GET ?celular=88112233
// Retorna datos del operario si tiene permiso pitayabot activo
require_once __DIR__ . '/../../../conexion.php';
require_once __DIR__ . '/../auth.php'; // Verifica WSP_TOKEN del header

$celular = trim($_GET['celular'] ?? '');
if (!$celular) {
    echo json_encode(['success' => false, 'message' => 'Celular requerido']);
    exit;
}

try {
    // Buscar operario activo con ese número y permiso bot activo
    $stmt = $conn->prepare("
        SELECT o.CodOperario, o.Nombre, o.Apellido, o.email_trabajo,
               o.email_trabajo_clave, o.bot_github_token, o.bot_github_repo,
               o.bot_github_branch, o.bot_github_vault_folder,
               o.bot_imap_host, o.bot_imap_port, o.bot_activo,
               c.CodAsignacionNivelesCargos
        FROM Operarios o
        LEFT JOIN Contratos c ON c.cod_operario = o.CodOperario AND c.Finalizado = 0
        WHERE o.Celular = ? AND o.Operativo = 1 AND o.bot_activo = 1
        LIMIT 1
    ");
    $stmt->execute([$celular]);
    $operario = $stmt->fetch(PDO::FETCH_ASSOC);

    if (!$operario) {
        echo json_encode([
            'success' => false,
            'registrado' => false,
            'message' => 'No estás registrado para usar PitayaBot. Contacta a RRHH.'
        ]);
        exit;
    }

    echo json_encode(['success' => true, 'data' => $operario]);
} catch (Exception $e) {
    echo json_encode(['success' => false, 'message' => $e->getMessage()]);
}
```

## 2.4 — Lógica de buscar_tarea (flujo multi-paso)

Cuando el usuario pide finalizar/modificar una tarea por nombre, puede haber ambigüedad:

```
1. PHP busca tareas del usuario WHERE titulo LIKE '%palabras_clave%'
2. Si 0 resultados → "No encontré tareas que coincidan con '[búsqueda]'"
3. Si 1 resultado → mostrar título y pedir confirmación directa
4. Si 2-5 resultados → listar con números y preguntar cuál:
   "Encontré varias tareas:
    1️⃣ Revisar inventario (vence 25/03)
    2️⃣ Revisar proveedores (vence 28/03)
   Responde con el número de la tarea."
5. Si >5 resultados → pedir más detalle: "Hay muchos resultados, sé más específico."
6. Guardar lista en datos_parciales del estado de confirmación
7. Cuando responde con número → recuperar estado → ejecutar acción sobre la tarea elegida
```

```php
<?php
// api/bot/tareas/crear.php
// POST: cod_operario, cod_cargo, titulo, descripcion, fecha_meta, prioridad
require_once __DIR__ . '/../../../conexion.php';
require_once __DIR__ . '/../auth.php';

$body = json_decode(file_get_contents('php://input'), true);

    exit;

try {
    $stmt = $conn->prepare("
        INSERT INTO gestion_tareas_reuniones_items
          (tipo, titulo, descripcion, cod_cargo_asignado, cod_cargo_creador,
           cod_operario_creador, fecha_meta, estado, fecha_creacion)

    $id = $conn->lastInsertId();

    echo json_encode([
        'success' => true,
        'data' => ['id' => $id],
        'message' => "Tarea '$titulo' creada exitosamente."
    ]);
} catch (Exception $e) {
    echo json_encode(['success' => false, 'message' => $e->getMessage()]);
}
```

## 3.4 — Generador ICS (icsGenerator.js)

```javascript
// wsp-pitayabot/src/utils/icsGenerator.js

function generarICS({ uid, titulo, descripcion, fechaInicio, duracionMinutos = 60,
                       organizador, participantes, sequence = 0, method = 'REQUEST' }) {
  const dtstart = formatICSDate(fechaInicio);
  const dtend = formatICSDate(new Date(fechaInicio.getTime() + duracionMinutos * 60000));
  const dtstamp = formatICSDate(new Date());

  const attendees = participantes.map(p =>
    `ATTENDEE;CN=${p.nombre};RSVP=TRUE:mailto:${p.email}`
  ).join('\r\n');

  return [
    'BEGIN:VCALENDAR',
    'VERSION:2.0',
    'PRODID:-//Batidos Pitaya//PitayaBot//ES',
    `METHOD:${method}`,
    'BEGIN:VEVENT',
    `UID:${uid}`,
    `SEQUENCE:${sequence}`,
    `DTSTAMP:${dtstamp}`,
    `DTSTART:${dtstart}`,
    `DTEND:${dtend}`,
    `SUMMARY:${titulo}`,
    descripcion ? `DESCRIPTION:${descripcion}` : '',
    `ORGANIZER;CN=${organizador.nombre}:mailto:${organizador.email}`,
    attendees,
    method === 'CANCEL' ? 'STATUS:CANCELLED' : 'STATUS:CONFIRMED',
    'END:VEVENT',
    'END:VCALENDAR'
  ].filter(Boolean).join('\r\n');
}

function formatICSDate(date) {
  return date.toISOString().replace(/[-:]/g, '').split('.')[0] + 'Z';
}

function generarUID() {
  return `pitayabot-${Date.now()}-${Math.random().toString(36).substr(2, 9)}@batidospitaya.com`;
}

module.exports = { generarICS, generarUID };
```

## 4.3 — Cifrado de tokens GitHub

```javascript
// wsp-pitayabot/src/utils/crypto.js
const crypto = require('crypto');

const ALGORITHM = 'aes-256-cbc';
const KEY = Buffer.from(process.env.AES_SECRET_KEY, 'utf8').slice(0, 32);

function cifrar(texto) {
  const iv = crypto.randomBytes(16);
  const cipher = crypto.createCipheriv(ALGORITHM, KEY, iv);
  const cifrado = Buffer.concat([cipher.update(texto, 'utf8'), cipher.final()]);
  return iv.toString('hex') + ':' + cifrado.toString('hex');
}

function descifrar(textoCifrado) {
  const [ivHex, cifradoHex] = textoCifrado.split(':');
  const iv = Buffer.from(ivHex, 'hex');
  const cifrado = Buffer.from(cifradoHex, 'hex');
  const decipher = crypto.createDecipheriv(ALGORITHM, KEY, iv);
  return Buffer.concat([decipher.update(cifrado), decipher.final()]).toString('utf8');
}

module.exports = { cifrar, descifrar };
```

El PHP cifra el token antes de guardarlo en BD usando `openssl_encrypt`. El Node.js descifra antes de llamar a la API de GitHub. La clave AES vive en `.env` del VPS, nunca en BD.

## 4.4 — githubClient.js

```javascript
// wsp-pitayabot/src/utils/githubClient.js
const https = require('https');

class GitHubClient {
  constructor(token, owner, repo, branch = 'main', vaultFolder = '') {
    this.token = token;
    this.owner = owner;
    this.repo = repo;
    this.branch = branch;
    this.vaultFolder = vaultFolder;
  }

  // Crea o actualiza un archivo .md en el vault
  async crearNota(carpeta, nombreArchivo, contenido) {
    const path = [this.vaultFolder, carpeta, nombreArchivo]
      .filter(Boolean).join('/');
    const url = `https://api.github.com/repos/${this.owner}/${this.repo}/contents/${path}`;

    // Verificar si el archivo existe (para obtener SHA)
    let sha = null;
    try {
      const existente = await this.get(url);
      sha = existente.sha;
    } catch (e) { /* archivo nuevo */ }

    const body = {
      message: `PitayaBot: ${sha ? 'actualizar' : 'crear'} nota`,
      content: Buffer.from(contenido, 'utf8').toString('base64'),
      branch: this.branch,
      ...(sha && { sha })
    };

    return this.put(url, body);
  }

  // Lista todos los archivos .md del vault para búsqueda
  async listarArchivos(carpeta = '') {
    const path = [this.vaultFolder, carpeta].filter(Boolean).join('/');
    const url = `https://api.github.com/repos/${this.owner}/${this.repo}/contents/${path}`;
    return this.get(url);
  }

  // Obtiene contenido de un archivo específico
  async obtenerArchivo(rutaCompleta) {
    const url = `https://api.github.com/repos/${this.owner}/${this.repo}/contents/${rutaCompleta}`;
    const data = await this.get(url);
    return Buffer.from(data.content, 'base64').toString('utf8');
  }

  get(url) { return this._request('GET', url); }
  put(url, body) { return this._request('PUT', url, body); }

  _request(method, url, body = null) {
    return new Promise((resolve, reject) => {
      const options = {
        method,
        headers: {
          'Authorization': `Bearer ${this.token}`,
          'Accept': 'application/vnd.github.v3+json',
          'User-Agent': 'PitayaBot/1.0',
          'Content-Type': 'application/json'
        }
      };
      const req = https.request(url, options, res => {
        let data = '';
        res.on('data', chunk => data += chunk);
        res.on('end', () => {
          try { resolve(JSON.parse(data)); }
          catch(e) { reject(new Error('GitHub API parse error')); }
        });
      });
      req.on('error', reject);
      if (body) req.write(JSON.stringify(body));
      req.end();
    });
  }
}

module.exports = GitHubClient;
```

```javascript
// En notasHandler.js - buscar_nota
async function buscarNota(query, githubClient, geminiApiKey) {
  // 1. Listar todos los archivos del vault
  const archivos = await githubClient.listarArchivos();
  const nombres = archivos
    .filter(f => f.name.endsWith('.md'))
    .map(f => ({ nombre: f.name, ruta: f.path }));

  // 2. Pedir a Gemini que identifique los más relevantes
  const prompt = `
    El usuario busca notas relacionadas con: "${query}"
    
    Lista de archivos disponibles:
    ${nombres.map((n, i) => `${i+1}. ${n.nombre} (${n.ruta})`).join('\n')}
    
    Responde SOLO con JSON:
    { "indices": [1, 3, 7] }
    Los índices (1-based) de los archivos más relevantes, máximo 3.
    Si ninguno es relevante, responde: { "indices": [] }
  `;

  const relevantes = await llamarGemini(prompt, geminiApiKey);
  const indices = JSON.parse(relevantes).indices;

  // 3. Obtener contenido de los archivos relevantes
  const resultados = [];
  for (const idx of indices.slice(0, 3)) {
    const archivo = nombres[idx - 1];
    const contenido = await githubClient.obtenerArchivo(archivo.ruta);
    resultados.push({ nombre: archivo.nombre, contenido: contenido.slice(0, 500) });
  }

  return resultados;
}
```

```php
require_once __DIR__ . '/../auth.php';

$resultados = [];
if ($ids) {
    foreach (array_slice($ids, 0, 5) as $uid) {
        $header = imap_fetchheader($mbox, $uid, FT_UID);
        $estructura = imap_fetchstructure($mbox, $uid, FT_UID);
```

## Manejo de errores en Node.js

```javascript
// Patrón estándar para todos los handlers
async function manejarTarea(operario, entidades) {
  const inicio = Date.now();
  try {
    // ... lógica
    await registrarLog(operario.CodOperario, 'crear_tarea', mensaje, respuesta, true, null, Date.now()-inicio);
    return respuesta;
  } catch (error) {
    logger.error(`Error en crear_tarea:`, error);
    await registrarLog(operario.CodOperario, 'crear_tarea', mensaje, null, false, error.message, Date.now()-inicio);
    return '❌ Ocurrió un error procesando tu solicitud. Intenta de nuevo.';
  }
}
```
